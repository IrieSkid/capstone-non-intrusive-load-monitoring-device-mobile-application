## Writing Tips

### 1. Academic Writing Style
- Use third person
- Avoid contractions (don't → do not)
- Use formal language
- Cite all sources properly

### 2. Consistency
- Use consistent terminology
- Follow citation format throughout
- Maintain consistent formatting
- Use same abbreviations consistently

### 3. Figures and Tables
- Number all figures and tables
- Provide captions
- Reference in text
- Ensure clarity and readability

### 4. Citations
- Cite all claims
- Use recent sources when possible
- Balance local and foreign sources
- Follow your institution's format

### 5. Proofreading
- Check grammar and spelling
- Verify all numbers and data
- Ensure consistency
- Get peer review

## Common Mistakes to Avoid

1. **Plagiarism**: Always cite sources properly
2. **Inconsistent Formatting**: Follow style guide
3. **Missing Data**: Ensure all claims are supported
4. **Poor Grammar**: Proofread carefully
5. **Incomplete Sections**: Complete all required parts
6. **Missing Figures**: Include all diagrams
7. **Weak Conclusions**: Base on actual findings
8. **No Recommendations**: Provide actionable recommendations
