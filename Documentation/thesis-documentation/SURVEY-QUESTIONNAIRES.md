## QUESTIONNAIRE ADMINISTRATION GUIDE

### When to Use Each Questionnaire

1. **Questionnaire 1 (Requirements Survey)**: 
   - **When**: Before system development
   - **Who**: All potential users (tenants and landlords)
   - **Purpose**: Gather requirements and expectations

2. **Questionnaire 2 (SUS)**: 
   - **When**: After 1-2 weeks of system use
   - **Who**: All users who tested the system
   - **Purpose**: Measure system usability

3. **Questionnaire 3 (User Feedback)**: 
   - **When**: After 2-4 weeks of system use
   - **Who**: All users who tested the system
   - **Purpose**: Gather detailed feedback and satisfaction

4. **Questionnaire 4 (ISO/IEC 25010)**: 
   - **When**: After system testing phase
   - **Who**: Technical evaluators and expert users
   - **Purpose**: Evaluate software quality characteristics

5. **Questionnaire 5 (Technical Performance)**: 
   - **When**: During system testing
   - **Who**: Technical evaluators and developers
   - **Purpose**: Measure technical performance metrics

6. **Questionnaire 6 (Pre-Deployment Checklist)**: 
   - **When**: Before final deployment
   - **Who**: Development team
   - **Purpose**: Ensure system readiness

### Administration Tips

1. **Informed Consent**: Always obtain written consent before administering questionnaires
2. **Privacy**: Ensure data privacy compliance (RA 10173)
3. **Anonymity**: Allow anonymous responses if preferred
4. **Time Management**: Inform respondents of estimated completion time
5. **Clarification**: Be available to answer questions
6. **Follow-up**: Thank respondents and share results if appropriate

### Data Collection Methods

- **Online**: Google Forms, SurveyMonkey, or similar
- **Paper-based**: For users without internet access
- **In-person**: For better response rates and clarification
- **Mixed**: Combine methods for maximum participation
